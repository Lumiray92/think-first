# ThinkFirst 架构

保留 Vue 3 + Vite 与 Spring Boot 3 / Java 17，复用现有登录、密钥托管和知识检索。

- app/src/lib/auth.js：统一认证请求与超时处理。
- app/src/composables/useCoach.js：会话状态、提交互斥和错误展示。
- server/.../coach：12 步流程、确认卡、闸门、需求字段结构。
- server/.../llm/SlotGenerationService.java：根据上下文生成结构化需求字段，独立于选项改写。
- server/.../llm/DeepSeekCoachLlm.java：选项和 PRD 生成适配。
- server/.../llm/HttpDeepSeekClient.java：模型请求、超时及截断检测。

字段生成独立配置 LLM_SLOTS_MAX_TOKENS（默认 4000）。模型读取超时默认 60 秒；一次回答可能串行生成字段与下一步选项，前端等待上限 150 秒。失败保留当前卡片和输入草稿。

本次拆分不迁移已有数据库。更新后需重启后端。真实模型回归需使用有效 Key 验证快速和完整模式。

## 文档调整与历史记录

完成页可选择公司详细版（目标3000–5000中文字）、Codex任务提示词、Claude Code任务提示词或自定义要求。调用同一会话的 polish 动作，以当前文档作为原稿。输出完整且成功后才替换当前文档，失败保留原版本。独立 polishMaxTokens 默认10000，调用计入用户用量。

浏览器按登录邮箱保存历史对话（问题、候选、回答、确认卡、文档版本），新对话不会删除历史。记录仅在当前浏览器可见，不是跨设备云端存储。历史用于查看，不恢复已过期的服务端会话。原有旧会话未记录的消息无法补回。

## 提示词框架与技巧

第10步使用 S.C.A.F.F.、R.G.C.、故事化 Prompt、万能模板。第11步才选择示例、自查等技巧。框架定义集中在 PromptFrameworks，需求字段生成会校验框架名称，导出文档解释组成要素。旧会话已经保存的 zero-shot 等值需重新生成第5组。

## 数据库会话与保护机制（2026-10-31）

- tf_conversation 表按会话标识保存归属账号、标题、更新时间及完整JSON快照；快照包含需求字段、当前卡片、对话和文档版本。所有读取和继续操作均校验当前登录账号。
- 本地默认H2文件数据库，生产配置MySQL；会话可从数据库重建，不依赖进程缓存。旧版本仅存在浏览器、且服务端已丢失的对话不能自动重建。
- 历史入口从数据库读取最近100条会话。浏览器中的记录只作显示缓存，不能作为服务器授权依据。
- 密码使用BCrypt单向哈希；增加UTF-8的72字节上限校验，不存在的邮箱也执行哈希比较。
- 密钥仍采用随机IV的AES-256-GCM加密，接口只返回掩码。敏感请求的toString隐藏内容，用户实体禁止序列化密码哈希和密钥密文。
- 登录、注册和密钥修改接口每来源每分钟最多10次；限流为单实例内存机制，反向代理环境须在可信代理层另配置限流。
- 响应禁止缓存；浏览器令牌改为标签页sessionStorage，默认有效8小时。此方案减少长期残留，但不是HttpOnly Cookie，仍须防止脚本注入。上线需要HTTPS、独立JWT签名密钥、独立主加密密钥，并备份主密钥与数据库。
- 顶部恢复原品牌；对话区的紫色小人提供“点我修改”悬停及键盘聚焦提示。

验证说明：前端生产构建通过；后端38项回归测试通过（包含数据库恢复与归属隔离、认证与密钥接口）；另通过独立Vite代理和H2测试数据库验证HTTP链路，未调用真实DeepSeek。Windows受限环境测试使用预加载Mockito代理及不分叉JVM运行。
