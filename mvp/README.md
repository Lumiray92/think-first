# ThinkFirst · MVP 原型

> 🖱️ **在线直接体验（不用下载，推荐）：<https://lumiray92.github.io/think-first/>**
>
> 💬 **想提意见 / 参与方案讨论：<https://github.com/Lumiray92/think-first/issues/1>**

一个**纯静态网页原型**，用来验证一件事：

> **「分阶段引导 + 边填边实时生成文档」能不能真的帮人在写第一行代码之前想清楚方向。**

不用注册、不用联网、不上传任何数据 —— 你填的内容只存在**你自己浏览器的 localStorage** 里。关掉浏览器还在，清掉浏览器数据就没了。

---

## 一、本地运行

### 方式 A：直接打开（最快）

1. 下载本仓库
   - 点仓库页面右上角 `Code` → `Download ZIP`，或
   - 执行 `git clone https://github.com/Lumiray92/think-first.git`
2. 进入 `mvp/` 目录
3. **双击 `index.html`**，用 Chrome / Edge / Firefox 打开即可

> 不需要 `npm install`，没有任何第三方依赖，不需要构建步骤。

### 方式 B：起一个本地服务（复制功能体验最完整）

`file://` 协议下部分浏览器会限制剪贴板 API。原型已做降级处理（「复制为 AI Prompt」在双击打开时也能用，走的是 `document.execCommand` 兜底），但如果你要最稳的复制体验，起个本地服务。

在 `mvp/` 目录下任选一条执行：

```bash
# 装了 Python
python -m http.server 8000

# 装了 Node
npx serve .
```

然后浏览器打开 <http://localhost:8000/>

## 二、建议怎么走一遍（约 10 分钟）

| 步骤 | 你要做什么 | 请特别留意 |
|:---:|---|---|
| 1 | 打开首页往下滚，看「小周的失败案例」 | 这个场景你熟悉吗？ |
| 2 | 点「开始生成」进入工作台 | — |
| 3 | 依次走完 **定盘子 → JTBD → Pre-mortem → 功能自检** 四个阶段 | **你在第几个问题开始想跳过？** |
| 4 | 看右侧实时生成的文档 | 它长得像一份「能用的东西」吗？ |
| 5 | 点「复制为 AI Prompt」或「导出 Markdown」 | 导出来的东西你会真的拿去用吗？ |

每个字段下面都配了 **「为什么问这个」/「填错的典型样子」/「一个填对的例子」** —— 请留意这套引导到底有没有帮你把问题想得更清楚。

## 三、这个原型有什么 / 没有什么

**有**（就是 MVP 方案里筛选出的 3 个 P0 功能）：

- ✅ 分阶段引导填写（4 个阶段 / 12 个问题）
- ✅ 每个字段的引导层：为什么问 + 填错的典型样子 + 填对的例子
- ✅ 实时文档预览 + 一键复制为 AI Prompt + 导出 Markdown

**没有**（刻意不做，全部在「不做清单」里）：

- ❌ 账号体系、登录、云端保存
- ❌ Agent 对话式引导
- ❌ 七大思维模型（第一版只做 JTBD + Pre-mortem）
- ❌ 团队协作 / 评论批注
- ❌ PDF 导出 / 精美排版

完整的取舍理由、功能筛选表和不做清单，见 [需求前分析](../docs/需求前分析.md)。

## 四、文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 落地页：失败案例、「它怎么帮你」、「它不做什么」 |
| `guide.html` | 工作台：左侧引导表单 + 右侧实时文档预览 |
| `done.html` | 完成页：导出 / 复制入口与自检 |
| `shared.js` | 全部问题内容、阶段定义、文档与 Prompt 生成逻辑 |
| `styles.css` | 样式 |

> 想加一个新阶段？只用往 `shared.js` 的 `Q` 和 `STAGES` 里加数据，页面结构不用改。
